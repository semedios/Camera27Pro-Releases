# Privacy information — beta v0.3.4

The camera and microphone are used to capture photos and videos. Photos library add permission is used to save captures. The implemented recording and optional noise filter run locally on the device. The current app has no integrated analytics, payment or cloud processing service. Temporary recording and processing files may exist on the device. Sharing a recording is a user action. GitHub and third-party signing tools have their own privacy terms.

Do not include private recordings, Apple credentials, tokens or personal identifiers in public issues. This statement describes the current prototype; it is not an audited privacy certification.
